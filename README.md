# ♻️ EcoGrid – Smart Waste Management System

**A database-driven solution for smarter, more organized and efficient waste management.**

EcoGrid is a Smart Waste Management System designed to improve the way waste management activities are organized and monitored. The project uses a centralized database to manage waste-related information and support more structured waste management operations.

The goal is to simplify waste management processes, improve data organization and support better decision-making for municipal waste management.

## 🎯 Problem Statement

Traditional waste management processes often face challenges such as inefficient data handling, poor record management, lack of centralized information and difficulties in monitoring waste-related activities.

These challenges make waste management operations harder to organize and manage effectively.

## 💡 Solution

EcoGrid provides a database-driven platform that brings waste management information into an organized system.

By combining a web-based interface with database management, the project aims to make waste-related information easier to store, access and manage.

## ✨ Key Highlights

- **Centralized Database:** Organizes waste management information in a structured database.
- **Web-Based Interface:** Provides an interface for interacting with the system.
- **Data Management:** Supports organized storage and retrieval of waste-related records.
- **Database Integration:** Uses SQLite for persistent data storage.
- **Backend Processing:** Uses Python and Flask to handle application logic and database interactions.

## 🚀 Getting Started

### Prerequisites

- Python 3.10 or newer
- pip (Python package manager)
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/sahanap24csds-crypto/smart_waste_dbms.git
```

### 2. Navigate to the Project

```bash
cd smart_waste_dbms
```

### 3. Install Dependencies

Install the dependencies listed in your project's requirements file, if provided:

```bash
pip install -r requirements.txt
```

### 4. Run the Application

Run the appropriate Flask application entry-point file from the backend directory.

```bash
python app.py
```

*The entry-point filename and execution command should be adjusted to match your actual backend.*
